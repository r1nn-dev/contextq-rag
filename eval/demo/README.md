# eval/demo — 로컬 시연 질문셋과 기능 점검 결과

로컬 시연(`make up` → `http://localhost`) 전에 시연 동선을 점검한 결과와 시연에 쓸 질문을 둔다(R-10-2, #174).
질문과 기대 결과는 `questions.yaml`에 있다. 실험 질문셋(eval-v1)과 결과(`results/`)는 이 디렉터리와 관계없다.

## 시연 계정

| 계정 | 용도 | 한도 (정책서 §8.1) |
| --- | --- | --- |
| 일반 계정 | 단일·이어서 질문·비교·대화 이력 시연 | 하루 100회(비교 2회로 계산) · 분당 10회 · 동시 스트림 2 |
| 관리자 시드 계정 | 인덱스 현황·사용자 목록·잠금 해제·시스템 로그 | 일반 계정과 같음. 환경 변수 `ADMIN_EMAIL`·`ADMIN_PASSWORD_BCRYPT`로만 만든다 |
| 게스트 (시크릿 창) | "5회 → 로그인 유도"만 보여 줄 때 | 브라우저 세션당 24시간 5회 → 관람객 여러 명에게 나눠 줄 수 없다 |

- 비교 질문은 3개를 모두 해도 일일 한도 6회만 쓴다.
- 인증 경로는 IP당 10회/분·burst 5다. 페이지를 새로 열 때마다 refresh·me 2회가 나가므로 연속으로 새로고침하지 않는다.

## 기능 점검 결과 (2026-11-18)

환경: 로컬 시연 스택(nginx·backend·ai-server·postgres), ACTIVE run 6(v0.3)·10(v1.x), gpt-4o-mini.
화면 항목은 Playwright(chromium)로 nginx를 거쳐 실제 화면을 조작했고, API 항목은 nginx를 거쳐 호출했다.

## 관찰 (결함 아님, 후속 참고)

- 한국어 질문은 유사도가 낮다(R-11-5). Q-shared 한국어 원문 비교는 두 요약이 비슷하거나 한쪽 근거가 없어, 비교 시연에는 영어 번역 2개와 확인한 한국어 1개를 쓴다.
- v1.x 단일 질문 RET-001 답변 코드에 v0.3 레거시 API(`initialize_agent`·`agent.run`)가 섞인 적이 있다. 생성 단계(L3) 버전 혼입으로, E3 실험의 관찰 대상이다.
- 한국어 RET-009는 근거 부족(LLM_ABSTAIN)으로 끝난다. OOS-009는 근거 부족 대신 "날짜가 문서에 없다"고 인용과 함께 답한다.
