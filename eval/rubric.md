# E3 블라인드 레이블링 루브릭 (초안)

> **상태:** 초안 — 외부 레이블러와 사전 조율 전 (`docs/experiments/eval-scenarios.md` 미결정 사항, `docs/experiments/evaluation.md` EV-1)
> **근거:** `docs/experiments/protocol.md` 실험 E3 · `docs/experiments/evaluation.md` §2.3 · §3.3

---

## 1. 대상과 절차

- 대상: Q-shared 20문항 × 버전 2(v0.3, v1.x) × 조건 4(L0·L1·R1·R2) = 답변 160개
- 레이블러: 2명이 서로 독립적으로 레이블링한다.
- 블라인드: 답변은 조건 코드를 지우고 무작위 순서로 섞어 제공한다. 레이블러에게 보이는 정보는 **질문, 선택 버전(v0.3 / v1.x), 답변 본문, 답변에 붙은 근거(R1·R2만 존재)** 뿐이다.
  - 근거 유무로 RAG 조건을 짐작할 수 있다. 이 한계는 보고서 타당성 위협에 적는다.
- 레이블러 간 일치도는 Cohen's κ로 보고한다. κ < 0.61이면 이 루브릭을 다시 협의하고, 바뀐 내용을 `eval/decision_rules.md`에 기록한 뒤 다시 레이블링한다(`evaluation.md` §5.2).
- 불일치 건은 두 레이블러가 논의해 최종 라벨을 합의한다. 합의 전 원본 라벨도 보존한다.

## 2. 레이블 항목

### 2.1 `version_error` — 버전 오류 (0 / 1, 모든 조건)

| 값 | 기준 |
| --- | --- |
| 1 | 답변이 **선택 버전이 아닌 버전의 코드·API·import 경로를 명시적으로** 권한다 |
| 0 | 선택 버전의 API만 쓰거나, 버전에 무관한 설명만 한다 |

판정 예시 (선택 버전 v0.3):

- 1: `from langchain.agents import create_agent` 를 쓰라고 안내 (v1.x API)
- 1: `langchain-classic` 패키지로 옮기라고 안내 (v1.x 마이그레이션 내용)
- 0: `AgentExecutor`·`create_react_agent`·LCEL(`prompt | llm`) 사용

판정 예시 (선택 버전 v1.x):

- 1: `AgentExecutor(agent=..., tools=...)`·`LLMChain`·`ConversationBufferMemory`를 그대로 쓰라고 안내 (v0.3 이하 패턴)
- 0: `create_agent`·미들웨어·체크포인터 기반 단기 메모리 사용

경계 규칙:

- 코드 없이 개념만 설명하고 버전 고유 API를 언급하지 않으면 0.
- 다른 버전 API를 "예전 방식은 이랬다"처럼 **대비로만** 언급하고 선택 버전 방식을 권하면 0.
- 두 버전에 모두 있는 API(`ChatOpenAI`, `@tool` 등)는 오류가 아니다.
- 판단이 어려우면 메모를 남기고 1로 두지 않는다(보수적 판정). 메모는 합의 단계에서 검토한다.

### 2.2 `evidence_quality` — 근거 충실성 (0 / 1 / 2, R1·R2만)

| 값 | 기준 |
| --- | --- |
| 2 | 답변의 핵심 주장마다 인용 근거가 있고, 근거 본문이 그 주장을 실제로 뒷받침한다 |
| 1 | 근거가 일부 주장만 뒷받침하거나, 근거는 있으나 주장과 느슨하게 연결된다 |
| 0 | 근거가 없거나, 근거가 답변 주장을 뒷받침하지 않는다 |

- L0·L1(범용 LLM)은 근거가 없으므로 `null`로 둔다.
- NO_CONTEXT 응답(안내 메시지만 반환)은 `null`로 두고 메모에 "NO_CONTEXT"라고 적는다.

### 2.3 `answer_usefulness` — 유용성 (0 / 1 / 2, 모든 조건)

| 값 | 기준 |
| --- | --- |
| 2 | 선택 버전 사용자가 이 답변만으로 질문한 작업을 할 수 있다 |
| 1 | 방향은 맞지만 빠진 단계가 있거나 추가 검색이 필요하다 |
| 0 | 질문과 무관하거나, 따라 하면 동작하지 않는다 |

- 버전 오류(`version_error = 1`)가 있는 답변은 유용성을 최대 1로 준다. 선택 버전에서 그대로 실행되지 않기 때문이다.
- NO_CONTEXT 응답은 0으로 둔다. 범위 안 질문(Q-shared)에서 근거를 못 찾은 것이기 때문이다.

## 3. 기록 형식

레이블링 결과는 `evaluation.md` §3.3 스키마로 기록한다. 레이블러별 원본과 합의본을 따로 남긴다.

| 필드 | 값 |
| --- | --- |
| `label_version_error` | 0 / 1 |
| `label_evidence_quality` | 0 / 1 / 2 / null |
| `label_usefulness` | 0 / 1 / 2 |
| `labeler` · `labeler_b` | 레이블러 식별자 (익명화) |
| 메모 | 경계 규칙을 적용한 근거 (선택) |
