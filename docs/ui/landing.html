핵심 요소

다른 LLM 도구와 무엇이 다른가

범용 LLM은 v0.3과 v1.x를 훈련 데이터 안에서 뒤섞어 가지고 있습니다. 버전을 명시해도 모델이 "요청"을 받을 뿐, 실제로 어떤 지식을 꺼낼지는 통제되지 않습니다.

버전 격리 검색
v0.3과 v1.x는 별도의 Chroma 컬렉션에 저장됩니다. 버전 선택이 쿼리 파라미터가 아니라 물리적 컬렉션 분리로 구현되므로, 혼입이 구조적으로 불가능합니다.
Chroma 컬렉션 분리 text-embedding-3-small
커밋 SHA 고정 출처
모든 답변에 섹션 경로와 GitHub SHA 고정 permalink가 포함됩니다. URL은 자동으로 HTTP 200 검증되며, 수집 커밋과 날짜가 함께 표시됩니다.
permalink SHA 고정 자동 검증
NO_CONTEXT 처리
검색 결과 유사도가 임계값 미만이면 LLM 호출 없이 "근거를 찾지 못했습니다"를 반환합니다. 환각된 답변 대신 명확한 한계를 알려줍니다.
임계값 필터 NO_CONTEXT 환각 방지
버전 비교 모드
